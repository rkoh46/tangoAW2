# The BH2 Campaign's maps: pipeline, rules, pictures (`aw2dev maps gen --campaign bh2`, `aw2dev bh2`)

The BH2 Campaign (docs/BH2_CAMPAIGN.md) plays Black Hole against the Allies on the AW1-style world. Its mission maps are built exactly as the Emerald Sun maps are: each map is a small
Python spec, the spec writes a text map, `five/bhmap.py` turns the text maps into Rust data. Nothing is registered in a menu yet: maps and pictures come first. No ROM content is stored;
the ROM is read at run time for tile choices and the lint.

## Files
| Path | What |
|---|---|

| `tango-gamesupport-aw2/five/bh2/` (`bh2_01.txt` ..) | GENERATED text maps (`aw2dev maps gen --campaign bh2`); edit the spec |
| `tango-gamesupport-aw2/src/bh2_map_data.rs` | GENERATED by `five/bhmap.py --campaign bh2` (tiles joined as AW2 draws them; units) |
| `tango-gamesupport-aw2/src/bh2_maps.rs` | Rust tests over the data (maps present, size limits, at most 50 units an army, the named crate truck, the sky front's air) |
| `devkit/aw2/esmaplib/__init__.py` | the shared `Canvas` (a `bh2_` name selects the BH2 folder): painting, `place` (properties near roads, spaced), `stamp` (inventions with their footprints), `shore` (beaches), `land_rows`, `sea_near`, `spread` |
| `devkit/aw2/bh2lib/` | mission table, review pictures (`pictures.py`), the world-map flag check, the feature report, tests (`test_bh2.py`) |

| `devkit/aw2/maplint/rules.py` | source `bh2` in every rule; IV01 (inventions are Black Hole's); AR02 lets a held second HQ `Q` stand beside an army's HQ |

## Commands
| Command | What |
|---|---|
| `aw2dev maps gen --campaign bh2 [--map bh2_03] [--no-build] [--principles]` | specs -> text maps -> `bh2_map_data.rs`; `--check` fails when a text map differs from its spec |
| `aw2dev maps lint --source bh2 [--map ..] [--warn] [--png DIR]` | the integrity rules, the design rules (DQ.., SP.., MD.., PP03/04 fail as for Emerald Sun) and IV01 |
| `aw2dev maps features --campaign bh2` (or `aw2dev bh2 features`) | which properties, terrain and inventions each map uses; what no map uses yet |
| `aw2dev maps render-check --source bh2 [--pictures DIR]` | RN01 on the game's own pictures of the maps (wired in; the pictures exist once the missions are in the game: `aw2dev campaign sheets` / `maps boot` for BH2 come with the campaign registration) |
| `aw2dev bh2 pictures [--out DIR]` | `m01.png`.. (the full map, fog off, every unit, labelled), `m01_fog.png` (the player's view), `act1_sheet.png`, `worldmap_flags.png`; `MISSION N - Title` burned in |
| `aw2dev bh2 check` | every mission flag on the picture world map lies on land inside its nation |

## The owner's rules, and where each is enforced
- **Inventions** (Deathray, Black Cannons, minicannons, Lasers, Black Crystals, Black Obelisks, Black Factory) are Black Hole's alone: **IV01** (error) refuses one that stands nearer to another army's HQ than to Black Hole's.
  The Deathray goes at most once a map, at the top edge (IV01 checks the row); none in Act I (a test).
- **Rivers** run source to sea or lake with mouths: RV01..RV05 (errors), the mouths and bridges by `Canvas.river` / `bridge`; a river is never cut by a road without a bridge (RV04).
- **Terrain**: SE01..03, TJ01..03 and RN01 (proper coast, shoal and cliff transitions), GB01/02, UN01..04 (no unit on impossible terrain), RC01..04 (no unreachable land, a Lander has a beach), RD01..02, PP01..04.
- **Beaches**: AW2 draws a beach one cell wide and long runs only along north- and south-facing coasts (the learned tile pairs refuse a shoal on a shoal and a long vertical run: TJ01/TJ02). So
  the island maps face their beaches north and south and run them for 8 to 12 cells: `shore(m, 1, box, dirs="NS")`; a test measures the longest run. Ports keep an open sea cell beside them.
- **No pointless Anti-Air**: an army fields AA or Missiles only where its opponents have or can build air (M3: Javier's airports and Fighters; M4 front 1: Drake's airport; M5: the Allies' air; M1 and M2: none).
- **No decorative filler, room to fight**: MD01..MD08, DQ04/05/08, SP01, the same thresholds as Emerald Sun; roads lead to properties (`Canvas.place` keeps every property near a road).
- **Units**: at most 50 an army, one HQ an army (the held second HQ of M5 is a `Q`, as BH1's M30), deployed units start at full strength (the builder gives full ammo and fuel), every army its own colour.
- **Fog missions** (M1): `aw2dev bh2 pictures` writes the full map with fog OFF and the fogged view (vision approximated: each unit's range by Manhattan distance, owned properties one cell).
- **Sky front** (M4's second map): `nohq`, air only, no property, no airport, no B Copter (BH1's M15 rule), exempt from the design rules.

## World-map flags
`world_picture::BH2_FLAGS` (Rust) names each mission's flag place on the picture world map: M1 (38, 204), M2 (18, 214) and the secret M26 (30, 222) on **Black Hole's own island** (the grey island, bottom left),
M3 (96, 173), M4 (150, 215), M5 (115, 140) in Green Earth. Black Hole's island is Black Hole's from the start: `PictureMap::conquered` always includes its class (5), so it is drawn in Black Hole's colours and
its missions never change it. Checks: `aw2dev bh2 check` / `bh2lib.check_flags` (on land, inside the declared nation, two pixels from any rim) and the Rust test `world_picture::tests::bh2_flags_lie_in_their_nation`.
Picture: `aw2dev bh2 pictures` writes `worldmap_flags.png`.

## Adding the next map
1. Write the next spec in `five/bh2/spec/` (named `bh2_` and the mission number; read docs/dev/map-design.md first: where the fight is, lanes, properties, threats and answers, in the doc string), add the mission to `bh2lib.MISSIONS`.
2. `aw2dev maps gen --campaign bh2 --principles`, `aw2dev maps lint --source bh2 --warn`, `aw2dev bh2 pictures` and LOOK at every picture (rivers, beaches, symmetry, cramped fronts).
3. `aw2dev bh2 features`: the coverage table; use what is missing where it fits the mission. `aw2dev test python`, `cargo test -p tango-gamesupport-aw2 --lib bh2_maps world_picture`.
