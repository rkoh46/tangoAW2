# Online map pool

Every map the online SELECT MAP can list, with its armies **counted from the map data** (the owners of its
property tiles and of the units placed on it), not from AW2's labels. Generated by
`cargo run --release -p tango-gamesupport-aw2 --example aw2_map_audit -- <AW2 rom> --md` (with
`TANGOAW2_DS_ROM=<nds>` for the Dual Strike table); the example exits 1 when a map's data disagrees with its header.
A unit test (`five_map::tests::every_map_has_the_armies_it_is_listed_for`) checks tangoAW2's own maps the same way.

A room of N players sees two tabs: "NP" and "NP Predeploy" ("NP - Predeploy" is two letters too wide for the game's
tab box). A tab with no map is hidden.

**Pre-deployed** means the map's unit list places units for the armies at the start.

**5P limitation:** every 5-army map is pre-deployed (the nine below), so a 5-player room has only the "5P Predeploy" tab;
there is no 5P map without pre-placed units yet. (Maps marked tangoAW2 with the Black Obelisk or Dual Strike art
need that art to be listed.)
