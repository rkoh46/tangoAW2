# Crumb's art

Original tangoAW2 pixel art (GPL-3.0-or-later), drawn with `tools/crumb_art/`
(`python3 tools/crumb_art/build.py` writes these files). Not taken from any
game. Per version (A: saluting with the flag on his shoulder, B: arms crossed
with the flag on his back, C: a cheerful thumbs-up): `body.png` (128x160),
`face_normal|happy|sad.png` (48x48), `mini.png` (32x24), `hud.png` (32x16),
all 4-bit indexed with one 16-colour palette, index 0 transparent.
